## 1. Model

### 1.1 Landau level and orbitals
- 2s flux quanta through the sphere, lowest Landau level, s = (N − 1)/2; each flavour has N orbitals m = −s…s.
- Four flavours at half filling, N_e = 2N electrons.
- The flavours form two **segments** A = (f₁, f₂) and B = (f₃, f₄); the in-segment pairing is Δ_seg = c_{f₁}c_{f₂}
  (matrix `[0 1; 0 0]`). Each segment carries an SU(2) flavour symmetry, SU(2)_A × SU(2)_B ⊂ Sp(2) ≅ Spin(5).
- Every operator is written as "in-segment terms + segment couplings" (FuzzifiED `SO3lver`, 2+2 segments).

### 1.2 Hamiltonian
H(g) = H_den − g · H_pair (`src/model.jl: build_terms, set_g!`), both terms with the V₀ pseudopotential only (V₀ = 1):
- **H_den**: in-segment `SingleSegCouple(2, p, GetDenIntTerms(N, 2), [0,0,0])` for p = A, B, plus
  `2 · CoupleDecomps([n, n], ConvPsPot(RecoupleAngMom(s, [1]))…)` between segments, n = `GetDensityMod(N, 2, I₂)`;
  together the V₀ contact interaction of the total four-flavour density.
- **H_pair**: in-segment `GetPairIntTerms(N, 2, [0 1; 0 0])` plus the segment coupling
  `CoupleDecomps([Δ′, Δ], ConvPsPot(s, [1])…, [2 −2; 0 0; 0 0])` and its reverse, Δ = `GetPairingMod(N, 2, [0 1; 0 0])`;
  together the V₀ channel of (Δ_A + Δ_B)†(Δ_A + Δ_B).
- The g-independent template `nn + dd` is assembled once; `set_g!` only rewrites channel coefficients
  (density channels unchanged, pairing channels × (−g)); all channel coefficients must be real (imaginary part < 1e-11).
- U_{m₁m₂m₃m₄} = Σ_l V_l (2N − 2l + 1)(s s N−l; m₁ m₂ −m₁−m₂)(s s N−l; m₄ m₃ −m₃−m₄) (FuzzifiED `GetIntMatrix`).

### 1.3 SO(5) Casimir
`src/model.jl: build_terms`. In-segment `GetC2Terms(N, 2, :SU) + (n_f − 2)/4 · GetPolTerms(N, 2)` (n_f = 4);
segment density coupling with every rank l = 0…2s weighted by `cross_density_coefficient(N)` = −½ for odd N,
+½ for even N (`src/so5_c2_density_phase.jl`; the sign compensates the (i)^{2m} phase that the pinned
`GetDensityMod` attaches to the modes); segment pairing coupling −1 for even l.
Normalisation C₂(5) = 2, C₂(10) = 3, C₂(14) = 5. Irrep identification (Dynkin labels ↔ C₂): `src/kkstage.jl: so5_types`.

**This odd/even phase is the only N-dependent branch of the physics in the code.**

### 1.4 Coupling g(N)
Fixed at every N by the finite-size condition F(g) = 0 (Δ_T = 3 when Δ_J = 2), see §4; reference values for N = 5–12 are in `configs/examples/`.
It is a finite-N matching, not a critical point; the code's own output says so.

## 2. Hilbert space and symmetry sectors

### 2.1 Segment spaces
`src/model.jl: segment_setup, build_segment_spaces` on FuzzifiED `BuildSegSpaces`.
- Quantum numbers of one segment: particle number n_e (0…2N), 2L_z (`GetLz2QNDiag(N, 2)`), flavour S^z = 0
  (`GetFlavQNDiag(N, 2, [1, −1])`); each n_e keeps the lowest |L_z| sector, `sec_pt = [n_e, ((N+1)n_e) % 2, 0]`.
- Multiplets: joint diagonalisation of L² (`GetLzLpTerms`) and the segment SU(2) Casimir (`GetC2Terms(N, 2, :SU)`),
  `l2c2_ratio = √2`; segment spin S_seg ∈ {0, 1, 2} (`c2_rng = S(S+1)`).
- **Gauge**: the basis inside a degenerate multiplet is whatever `eigen()` returns, so two builds differ; eigenvectors
  are meaningful only in the basis that produced them. Every `eig.ckpt` records the SHA-256 of its segment basis and
  every later step checks it.
- **Particle–hole half construction** (`src/ph.jl`, `basis.ph_half`): only n_e ≤ N is diagonalised, n_e > N is generated by
  P c†_{m,f}P⁻¹ = (−1)^{s−m} ε_f c_{−m,f̄}. Same multiplet subspaces as a direct build (only the multiplet gauge, hence the
  SHA, differs); N4–N12: |U′U − I| ≤ 1.3e-12, spectra ≤ 2.7e-13. Default "auto": see §2.5.

### 2.2 Composite blocks (s_A, s_B, L)
`BuildCompSpace([sp_A, sp_B], [2N, 0, 0], 2L)`: total particle number 2N, total flavour S^z = 0, highest weight of
total angular momentum L. A block is named `s{a}_s{b}_L{L}` with a ≤ b the SU(2) spins of the segments; every SO(5)
multiplet appears in several (s_A, s_B) blocks (N12: (1,1) vs (0,x) copies agree to |ΔE| ≤ 6.9e-9, parity 184/184).
The **integer sectors** are the six pairs (a, b), 0 ≤ a ≤ b ≤ 2; the **half-integer sector (½,½)** has odd n_e per segment,
segment spin ½ and Q = [2N, 0, 2] (used by the pipeline OPE, by ope3 and by Stage B, §9–§11).

### 2.3 Segment exchange X
`src/exchange.jl`. On diagonal blocks (s, s, L) the segment exchange (FuzzifiED `PermFirstSecondSegs`, with the SO(3)
recoupling sign; fermion sign +1 because each segment holds an even number of particles) is checked to be a signed
permutation with X² = 1. X = ±1 are solved separately in reduced spaces of about half the length,
e_k = (|i⟩ + c_k|j⟩)/√2 (or |i⟩ on fixed points). Off-diagonal blocks carry X = 0.

## 3. Diagonalisation

### 3.1 Solver (`src/runner.jl: lowest`)
- n ≤ 400: dense, matrix built column by column, `eigen(Symmetric((M + M′)/2))`.
- Otherwise KrylovKit Lanczos, `eigsolve(f, x₀, k, :SR, Lanczos(krylovdim, tol, maxiter=500))`,
  x₀ = normalize(randn(MersenneTwister(seed), n)); Krylov dimension min(max(2k, k+10), 100) for k ≤ 90, else
  k + max(30, ⌊k/2⌋); `spectrum.tol` = 1e-10; only the k lowest converged pairs are kept.
- Fixed seeds: blocks 1000a + 100b + 10L + (σ+1) (σ = X sector; deflated extension + 7919); target windows
  71231 + 100a + 10b + l + 7(σ+1) (deflation + 104729); independent target check 99871 + 100a + 10b + l (+13σ);
  tune 5052026 + 100s_A + 10s_B + l (final solve + 7919); pipeline half sector 424242 + k; Stage B 88000 + 100L + k,
  complement checks 77100 + L (prior) and 99000 + L (final).
- **Reproducibility**: with fixed seeds the results are reproducible to rounding; threaded BLAS makes the last bits,
  and hence the arbitrary sign of eigenvectors, differ between processes (matrix elements may flip sign; magnitudes,
  energies, C₂ and parities agree to ~1e-13). Compare magnitudes when you compare runs.

### 3.2 Windows and coverage
- Each block and X sector solves the lowest `nev` states (`block_nev`, `parity_nev` override per block/sector).
- **Coverage step** (`src/post.jl: run_coverage`, `[coverage] delta_cut, kmax`): after the first solve, every sector
  whose window is not the whole sector and ends below Δ_cut = 6.0 is enlarged to k = min(dim, k_max, max(n + 8, ⌈1.6n⌉)),
  k_max = 400, with `spectrum.extend = true` (stored vectors kept bit for bit, only new states solved by deflation),
  until all reach Δ ≥ 6.0 or are complete (≤ 50 rounds). Original study: N5, N6 one round, others none.
- **Deflation** (`lowest_deflated`): g = QHQ + σP, P = V₀V₀′, σ = 10 max|E_ref| + 100; new states are orthogonalised to the
  old space, QR, Rayleigh–Ritz; a new state below the old top − 1e-8 is an error (the old window was not a complete prefix).

### 3.3 C₂ polishing (`src/targets.jl: polish_c2!`)
Columns with C₂ residual above the trigger (1e-6 blocks, 1e-7 targets) are rediagonalised in C₂ together with all states
of the same X sector within 1e-3 in energy; groups with equal C₂ (≤ 1e-6) are Rayleigh–Ritz rotated in H. Frozen columns are
never touched. Target windows first resolve numerically degenerate clusters (≤ 1e-7) in C₂ (`resolve_c2!`).

### 3.4 Acceptance gates (`src/gates.jl`, hard, never relaxed)
‖Hv − Ev‖, ‖Cv − c₂v‖, column norm error, ‖V′V − 1‖_F ≤ 1e-6; C₂ within 1e-5 of an integer; energies finite and ascending;
fresh independent target check |ΔE| ≤ 1e-7, smallest subspace singular value ≥ 1 − 1e-5. Every column carries a SHA-256
that identifies it in incremental reuse. Residuals in practice are far below (N12 φ, J, T: ~1e-13).

## 4. Coupling tuning (`src/tuning.jl`)
F(g) = 2(E_T − E₀)/(E_J − E₀) − 3, with E₀ the lowest C₂ = 0 state of (0,0) L0 (X = +1), E_J the lowest C₂ = 3 state of
(0,1) L1, E_T the lowest C₂ = 0 state of (0,0) L2. Per g point the three anchors are solved with k = 8, 12, 24 and
tol 1e-9 (gates: residuals ≤ 1e-7, target C₂ within 1e-5, every state below the target C₂-resolved, a gap > 1e-6 at the
window end or the whole sector). Root finding (`find_root`): from `start`, points at ±0.005, ±0.015, ±0.035, ±0.075 and the
ends of `bounds` = [0.90, 1.12] until F changes sign; guarded secant inside the bracket (bisection when degenerate);
when |F| ≤ ftol = 1e-5 but the bracket is wider than xtol = 1e-4, two points at ±0.49 xtol around the best point.
Acceptance: anchor overlaps ≥ 0.95 with the nearest other g point, an independent final solve with other seeds still has
|F| ≤ ftol and agrees to 1e-7. The start only decides from which side the bracket is approached.
Reference values of the original study: `run.g` of `configs/examples/N*.toml`. The criterion uses only the spectrum of
the model itself (the form of the condition follows arXiv:2306.16435); it does not claim that g* is a critical point.

## 5. Energy scale
Δ = α(E − E₀), α = 2/(E_J − E₀) (Δ_J = 2; at g* also Δ_T ≈ 3). Same α in the summary and in the KK fit, computed
independently. No finite-size correction, no extrapolation.

## 6. KK target windows (`src/targets.jl: extend_targets`)
For every source block L_i the KK step needs complete lowest windows of L_f ∈ {L_i − 1, L_i, L_i + 1} (L_f = 1 only for
L_i = 0): target windows of L = 0…source_lmax + 1, source_lmax = max(`spectrum.lmax`, largest block L).
- Required energy: the highest neighbouring source energy, capped at E₀ + `source_delta_max`/α (original study 6.2; sources above
  it are reported as `partial_source_coverage`).
- Frontier: +∞ for a whole sector; the window top if the last gap exceeds `guard` (1e-5); −∞ inside a degenerate cluster.
  Complete when frontier > need + guard. A run window that already satisfies this and passes the gates is reused.
- Fresh growth (`target_growth = "fresh"`): first k estimated from the block's own spectrum (×1.15 + 8, or extrapolated
  ∝ (E − E₁)^{1.5}, ×1.1 + 8); after a failure k ← max(k + 8, ⌈1.5k⌉, extrapolation) up to `max_nev`; at the cap
  `INCOMPLETE_TARGET_WINDOW` (never silently truncated).
- Independent check (default `complement`): the 2 lowest states orthogonal to the window, other seeds; margin < −1e-7 is
  `GATE_FAIL`, −1e-7…guard grows the window.
- Original study: `initial_nev` = nev of the run, `max_nev` 4000 (N5–11), 400 (N12), `target_parity = "both"`.

## 7. KK projection (primary candidates; `src/kkstage.jl`, `src/ZhouGenerator.jl`)
- Generator candidates: l = 1 components of O₁ = (n†n) and O₂ = (Δ†Δ) (`GetDensityObs`, `GetPairingObs(…, mom_incr=false)`,
  `ObsNormRadSq = N`; pairing m → −m with i^{2m}; segment couplings × 1/(N√(4π)), density × 2, both orders of pairing;
  O₂ sign flipped for odd rank); K = c₁O₁ + c₂O₂, lowering part only.
- **Vacuum fit** (`kk_calibration!`, `fit_vacuum_generator`): reference v (vacuum), s (second C₂ = 0 state of (0,0) L0) and
  ∂S (C₂ = 0 state of L1 closest to E_S + 1/α); minimise the vacuum leakage c′Gc subject to Σ_p c_p⟨∂S|O_p|S⟩ = √(2Δ_S)
  (eigen-decomposition of G with rtol 1e-11).
- **Edges**: overlaps T′O_pS and image Gram ⟨O_pS_j, O_qS_j⟩; the generator must not change C₂ (≤ 1e-6‖M‖);
  energy_atol = max(1e-8, 10(r_S + r_T)).
- **Guarded sources**: all needed L_f present and E_i < frontier_f − energy_atol for every edge.
- Per integer C₂ channel: K² = Σ_{L_f} (2L_f + 1)/(2L_i + 1) K′K over the lowering elements; checks: captured ≤ image norm
  (1e-7), K² ≥ −1e-8; the eigenspace with K² ≤ threshold is diagonalised in energy → projected modes (energy, mixing residual).
- Thresholds [0.05, 0.1, 0.25, 0.5]; report and OPE basis 0.25. Channel status `finite_saved_window_complete_K_action`,
  `partial_source_coverage` or `incomplete`; never `CFT_primary_certified`.

## 8. Pipeline OPE (`src/ope.jl`)
Γ² insertion n_l = n_A − n_B (`GetDensityObs(N, 2, I₂; norm_r2 = N)`, `FilterL2`), edges [[0,0,0],[2,0,2]] on (0,0);
n = |⟨φ|Γ²₀|0⟩|; f_φφS, f_φφT14 (×√5/2), f_φφstress (×√(15/8)) on raw, L0-projected and L0+L2-projected bases;
φ×φ singlet and T14 towers. Half sector (½,½) (`ope.half`): L0 (C₂ 2, 5) and L1 (C₂ 3) windows, k = 6, 10, 16, 24,
f_φφJ = √3|⟨J|Γ²₁|φ⟩|/n, f_φφT_half = √2|⟨φ|Γ²₀|T⟩|/n, signed conjugation gates ≤ 1e-7.

## 9. Three-point insertions and extended OPE (`src/ope3.jl`, step `ope3`)
Options: `src_dmax` 5.0, `pair_dmax` 6.5, `int_ranks` [1,2,3,4], `half_lmax` 3, `half_nev` 24, `threshold` 0.25,
`image_bytes` (speed only), `qg_gate` (N ≤ 7), `half_only`.
Insertions: Γ² of any rank; singlet O_S = b_ρ(ρ†ρ) + b_Δ(Δ†Δ) (ranks 0 and 2, fixed by ⟨stress|O_S^{(2)}|0⟩ = 0 and
⟨S|O_S|0⟩ = Z_S = ±1, sign of S fixed by ⟨φ|n₀|S⟩ > 0); tensor Q_G with G = (−Q₁₁ + 4Q₂₂ − Q₃₃ − Q₄₄ − Q₅₅)/√20 in
exact Fierz form (`ObsNormRadSq = 1`), Z_T = |⟨T|Q_G|0⟩|. φ×φ → spin l: λ = c_l · CG · |⟨O_l|n_l|φ⟩|/|⟨φ|n₀|0⟩|,
c_l = √((2l+1)!!/l!). Gates: hermiticity < 1e-7, ⟨0|Q_G|0⟩ and ⟨S|Q_G|S⟩ vanish (< 1e-8 Z_T), half-sector selection rules.
The half-sector edges are bound to the window checkpoint SHA and g (v0.2.8, audit A3).

## 10. Physical parity P (`src/parity.jl`, step `parity`)
P is the particle–hole map c → Jc† (i → −i) of arXiv:2306.16435; in 2+2 segments the product of the two in-segment PH maps
P_seg (multiplet |n_e, l, α⟩ → |2N − n_e, l, β⟩, orthogonal U^{(l)} from stored representatives, error ≤ 1e-8).
P_phys = ⟨v|P_seg|v⟩ · ⟨vac|P_seg|vac⟩ · (−1)^L (P_seg contains m → −m). Every stored state must be a pure P_seg eigenstate
(residual < 1e-6). KK modes: ⟨P⟩ = Σ q_i² P_i (`mixed` if ||⟨P⟩| − 1| ≥ 1e-6). φφ towers get P by `tools/ope3_parity_join.py`
(step `parity_join`). N10 reproduces the parities of all 129 rows of Table VI of 2306.16435.

## 11. Stage B: the (½,½) and (1,1) sectors to the raw Δ cut (`src/stageb.jl`, step `stageb`)
Merged in v0.3.0 from three earlier per-N scripts (half sector and (1,1) for small N; half sector with spin range 0–3;
a memory-lean version with parallel window jobs for the largest N). Options in `[stageb]`.
1. **Raw windows** L = 0…lmax + 1 of the sector (`sector = "half"`: segment spin ½, Q = [2N, 0, 2], basis from ope3;
   `"11"`: the run's (1,1) basis), each grown (24 → ×1.5, cap `max_nev` = 384) until its frontier lies above
   E₀ + `raw_delta_max`/α (6.8) and the complement check (2 states, margin > guard) passes; prior windows (ope3 half windows,
   run (1,1) windows) are used only if they pass the gates and are a complete prefix. C₂ clusters resolved and polished;
   degenerate pairs rotated into P_seg eigenstates (`ph_resolve!`); gates as §3.4. A memory guard refuses a step that would
   exceed `memory_limit_bytes`. `step = "windows"` with `windows = [L…]` lets several jobs solve different L into one directory.
2. **Controls**: the vacuum P_seg sign is anchored on the lowest C₂ = 2 (half) / C₂ = 5 ((1,1)) state against the integer
   (0,0) L0 state of the same energy (≤ 1e-6); in the half sector the current J must have Δ = 2 (≤ 1e-6) and P = +1, and the
   raw φ–J element must reproduce ope3's (≤ 1e-7 relative).
3. **KK**: sources with E ≤ E₀ + raw_delta_max/α and C₂ ∈ {0, 2, 3, 5, 6, 8, 9, 10, 14}, lowering edges to L − 1, L, L + 1,
   classification per P_seg sector with the **integer run's generator coefficients** (§7) at threshold 0.25.
4. **Full-Q OPE**: projected scalar sources (Δ ≤ `source_delta_max` 5.0) × projected spin-l targets (Δ ≤ `target_delta_max` 6.6),
   l = 0…lmax, insertions Γ², Q_G (two parts each, combined later) and O_S; output `xy_blocks_raw.csv`, `projected_catalog.csv`,
   `kk_coverage.csv`, `raw_spectrum_Lle{lmax+1}.csv`.
5. **Raw targets** (`rawtarget = true` or step `rawtarget`): the same sources onto the full raw target windows; projecting them on
   the target modes must reproduce the step-4 edges and image Gram (≤ 1e-10 relative).
Identity: all checkpoints are bound to `input_binding.toml` (N, g, sector, raw Δ cut, calibration/normalisation/segment SHAs);
a restart reuses every window, edge and projection whose identity matches (audit A2).

**v0.3.1 additions** (seeds 88000 + 100L + k, thresholds and Hamiltonian unchanged):
6. **Window certificate** (`extra_states` = 4). Each growth step solves k + `extra_states` states. The saved window ends
   at the first index j ≥ k with E_j − E_{j−1} > guard and E_{j+1} − E_j > guard. The gap E_{j+1} − E_j is the complement
   margin, the same number the deflated complement solve of step 1 computes (its lowest state is state j + 1). The extra
   states are dropped before saving, so a window has as many states as with v0.3.0. The prior window is then not
   complement-checked: the first growth step deflates against it and stops if a new state lies below its top. A remaining
   complement check (`extra_states = 0`, or a step without a solve) uses `complement_tol` (1e-6, at most guard/10; the Ritz
   value error is bounded by the residual norm). Before the PH resolution the certified window is C₂-polished once more with
   trigger `final_polish_trigger` (1e-9). Without this pass, an N8 L2 pair with gap 1.7e-6 and C₂ = 10, 2 kept a
   path-dependent C₂ residual of 2.7e-8. The window checkpoint records `certificate`
   (`extra_states` / `deflated_complement` / `whole_sector`) and `complement_tol`; the manifest lists them per L.
   Why: on N12 L2 (D = 1.4×10⁸) the 1e-10 complement solve of an 81-state window ran for more than 29 h without
   finishing, while the observed margins were ≥ 3.3e-4 (33× the guard). `extra_states = 0`,
   `complement_tol = 1e-10` and `final_polish_trigger = 0` reproduce v0.3.0 exactly (same windows; checked on N6 when v0.3.1 was made).
7. **Partial checkpoints** (`partial_checkpoints = true`). Every growth step that does not yet guard the cut saves the
   window it carries into the next step to `windows/partial/L<L>_k<k>.ckpt` (older ones are removed after the new one is
   complete). A restart resumes from the largest k with the same next k and seed, i.e. on the step sequence of an
   uninterrupted run. `stop_after_k = k` (only with `step = "windows"`) stops cleanly once a partial window with ≥ k
   states is saved. Partials are removed when the window is saved. Cost: up to two partials per L on disk (N12 L2: 91 GB
   at 81 states).
8. **Preliminary top window** (`prelim_top_window = <partial checkpoint>`, `step = "all"`, lmax ≥ 1). A partial window
   (identity-checked like a resume) stands in for the raw window of L = lmax + 1, which is a KK target only. KK sources of
   every L are restricted to E < min over their targets of (frontier − atol), the guard the KK step otherwise asserts; the
   removed sources are listed in `prelim_truncated_sources.csv`. The partial window has no PH labels (pseg = P = 0 in
   `raw_spectrum`). The manifest status is `preliminary_partial_top_window_truncated_KK_sources` with a `[prelim]` table.
   `prelim_complement = true` runs the complement check of the partial window after the export
   (`prelim_complement_L<L>.toml`); a failure exits with an error but keeps the outputs. Example: with an unfinished L2 window,
   the half-sector KK/OPE of L0–1 is available early; φφJ does not depend on the L2 truncation, since K₂(J) = 0 (J is
   the lowest C₂ = 3 state of L0–L2). Keep such preliminary outputs apart from complete-window results.

## 12. Full-Q integer-sector OPE (`src/fullq.jl`, step `fullq`)
Merged in v0.3.0 from two earlier scripts (all sectors; a sector list for the largest N). For each selected (s_A, s_B) pair:
KK scalar sources (Δ ≤ 5.0) with their **full** saved coefficient vectors (no support threshold, an independent axpy probe
checks the contraction ≤ 1e-10) against the KK targets of rank l = 0…`rank_max` (Δ ≤ 6.6); singlet insertion on every pair,
Γ² and Q_G also on the diagonal pairs; parities joined from `parity_kk.csv` (every mode must have one, |ΔΔ| ≤ 1e-7).
`sectors` default: the order (0,1), (0,2), (1,2), (0,0), (1,1), (2,2) restricted to the run's blocks.

## 14. Limitations the reader must know
1. **Finite-size matching**: g(N) matched by Δ_T = 3, Δ scaled by Δ_J = 2, no 1/N correction; every OPE number is a raw finite-N estimate.
2. **N12 reference plan**: only (0,x) blocks with L ≤ 3 (KK sources to L3, targets to L4); no (1,1), (1,2), (2,2) KK; the C₂ = 14
   channel of (0,0) L3 has no guarded source; Stage B half only to raw L2 / KK L1. The complete N12 L2 half window
   (D = 1.4×10⁸, ~180 states) takes days on one node; §11 item 8 gives a preliminary route.
3. **Reused segment bases**: a `segment_spaces.ckpt` built by another code version can be reused (`basis.segment_checkpoint`)
   if it spans the same multiplet subspaces as a build of the current code; for the N11 and N12 bases of the original study this
   was checked directly (‖UᵀU − I‖ = 3.1e-14, ‖B − AU‖ = 1.4e-12). Bitwise reproduction of eigenvectors needs the same basis
   files; physical numbers do not.
4. **g provenance**: the g values of `configs/examples/` were selected by earlier versions of the same algorithm and are written
   into the plans as numbers; F at the final windows is re-evaluated in each `physics_report.toml` — check it for your runs.
5. **Regression**: v0.3.0 was compared with the earlier per-N code on N5 and N6 only (differences of the size of run-to-run noise,
   ≤ 2e-11 absolute); larger N were not recomputed with v0.3.x.
