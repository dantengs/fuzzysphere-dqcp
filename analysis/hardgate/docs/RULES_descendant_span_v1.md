## S1 后裔空间截断（与顺序无关）
在每个 (pair, L) 的分类基上：

1. 设 H = [B₁ | B₂ | …]，为该 (pair, L) 上所有家族块按列拼接。每个 B_f 都是 v0.3.5 中 `_orth_top` 给出的正交归一列，零像截断 `NULL_SV = 0.3` 不变。
2. 对 H 作 SVD：H = U Σ Vᵀ。保留满足 **σᵢ² ≥ 1 − g（= 0.10）** 的左奇异向量，它们张成的空间就是后裔空间 D。这一步取代 `_orth(hstack, rtol=1e-6)`。
3. **依据**：H Hᵀ = Σ_f Π_f，即各家族投影之和。两个单位方向的重叠为 c 时，H Hᵀ 的本征值为 1 ± |c|。
   - 近重复（|c| → 1）给出接近 0 的本征值，被截去；
   - 真正新增的方向贡献 ≈ 1，被保留；
   - 同一家族内部，以及彼此正交的家族，σ = 1，不受影响。
   截断值取 1 − g，语义与"权重 ≥ g 算落在空间内"一致。
4. **来源记录**：每个被截去的奇异方向，用右奇异向量 Vᵢ 在各家族列上的分量，给出它主要来自哪些父 primary、哪一级。写入 `descendant_span_dropped.csv`。
5. **对照 S1′（贪心）**：按提案 R1 的顺序（级数 → 父 Δ → 家族内奇异值）逐个接受，条件为 ‖(1−Π_A)u‖² ≥ 1 − g。只报告与 S1 分类不同的能级，用来量化顺序依赖，不作为正式结果。

## S2 P/D 冲突（取代提案 R2 和 R3；不做 Gram–Schmidt）
对每个 (pair, L) 的每个量子数扇区 key = (C2, X, P)：

1. 设 Q 为该扇区在 κ_thr 下的 primary 子空间（v0.3.5 的 `Qs["mid"]`），D 为 S1 的结果。计算 Qᵀ D 的奇异值，其平方即主角余弦平方 cos²θᵢ，对应的主方向对记为 (pᵢ, dᵢ)。
2. **冲突**：凡 cos²θᵢ ≥ g 的方向对都是冲突对。
   - 把 dᵢ 从 D 中移出，得到 D′；
   - 把 pᵢ 从 Q 中分出，Q = Q_clean ⊕ span{pᵢ}；
   - 冲突空间 C = span{pᵢ, dᵢ}。
3. **维数说明**：若 d_P + d_D > n_s，按维数必有交集，cos² = 1，因此必然触发冲突。所以不再单设"维数预算"规则；overcomplete 只作为扇区标记报告。
4. **投影 primary 模式**：模式 m 在 span{pᵢ} 上的权重 ≥ 1 − g 时，标为 `conflict_pair`，在 S3 解除前不认证为 P。
5. **禁止的做法**：先把 D 对 Q 正交化，或先把 Q 对 D 正交化，再宣称某一方胜出。

### 原始能级分类（对称，取代 v0.3.5 的 P 优先顺序）
定义：
- pass_P′ = guarded 且 w(Q_clean) ≥ g；
- pass_D′ = w(D′) ≥ g；
- pass_old = (guarded 且 w(Q) ≥ g) 或 w(D) ≥ g。

按下列顺序判定，取第一个满足的类别：

| 顺序 | 条件 | 类别 |
|---|---|---|
| 1 | pass_P′ 且 pass_D′ | `ambiguous_primary_descendant_overlap` |
| 2 | pass_P′ | `primary` |
| 3 | pass_D′ | `descendant` |
| 4 | pass_old | `ambiguous_primary_descendant_conflict`（交给 S3） |
| 5 | 其余 | 沿用 v0.3.5 的 unclassifiable / nonprimary / mixed 规则，其中 w_P 取 w(Q)，w_D 取 w(D′) |

旧分类列 `cls_v035` 原样保留。

## S3 冲突解除（只用独立证据；默认维持 ambiguous）
适用对象：类别为 `ambiguous_primary_descendant_conflict` 或 `_overlap` 的能级，以及 `conflict_pair` 模式。

- **(a) 跨副本**：同一物理能级（phys_level_key）的另一个 (sA, sB) 副本所在扇区没有冲突，并且在 S2 中判为 primary 或 descendant，则支持该副本给出的一方。
- **(b) K² 预言**：在冲突后裔方向 dᵢ 上（不是在 primary 模式上）计算 ⟨dᵢ|K²|dᵢ⟩。
  - 前提：dᵢ 只落在 guarded 源上，否则这一项不提供证据。
  - 用 dᵢ 投影最大的家族确定父态 (Δ₀, L₀) 和级数 n，计算 λ = (2Δ₀+n−3)n + L(L+1) − L₀(L₀+1)（FFK 2602.04958 式 3.2）。
  - 若 λ < 1.0，属于近短化区，交给 T6，这一项不提供证据。
  - K²(dᵢ) < λ/2："它是该父态的第 n 级后裔"这一假设被否定，**支持 P**。
  - K²(dᵢ) ∈ [λ/2, 2λ]：**支持 D**。
  - K²(dᵢ) > 2λ：不提供证据。
- **(c) 缩窗稳定**：使用修复后的 T3。不稳定时计为"反对双方"。
- **判定规则**：至少一项支持某一方、没有任何一项支持另一方、且 (c) 不反对时，判为该方。类别写作 `primary_resolved` 或 `descendant_resolved`，并记录用到的证据。否则维持 ambiguous。
- **需要如实披露的局限**：primary 模式本身是按小 K² 选出的，而 dᵢ 与它的重叠 ≥ g，所以 (b) 与 KK 判据并不完全独立。(b) 的信息量来自 λ 这一独立预言。干跑必须单独报告"仅凭 (b) 解除"的案例数；如果这类案例占多数，附录要写明。

## S4 状态传播
- **物理副本合并**：按 phys_id 取各副本中最差的状态，而不是只取首个副本（对应复查 R2）。
- **轨迹**：只要有一个点的模式是未解除的 `conflict_pair`，轨迹状态就记为 conflict。
- **OPE**：X 或 Z 是未解除 `conflict_pair` 模式的行，身份状态标为 `ambiguous`，publishable = False。
- **不变的量**：κ 阈值、投影 primary 模式本身（Δ、向量）、跨 N 轨迹与命名、拟合，以及 OPE 数值。这些量都不依赖 D。只有身份状态和发布资格可能改变。干跑时要核验这些量与基线逐字节相同。
