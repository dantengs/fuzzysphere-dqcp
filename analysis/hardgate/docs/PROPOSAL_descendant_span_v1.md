# 提案：后裔空间的构造修正（草案 v1，2026-10-25）

**状态：只是提案。代码和分类都没有改。** 等你确认规则和适用范围后，先冻结规则，再做干跑（dry run）比较，最后才进入新版本。

## 1. 问题与诊断（数据：gate090 基线 + v0.4.0 强化层）
- **现象**：overcomplete 扇区共 26 个（N5 18 个、N6 4 个、N12 4 个），定义为 primary 维数 d_P 加后裔有效维数 d_D 大于该 (C2, X, P) 扇区的态数 n_s。24 个同副本双通过里，23 个落在这些扇区，其中包括 N12 的 4 个。在这些扇区里 w_D≈1 对每个态都成立，失去了区分力。
- **根源**：`spectrum.py` 用 `allD = _orth(np.hstack(各家族 B))` 构造后裔空间。每个家族的 B 是正交归一的，但**不同父 primary 的家族之间会彼此重叠**，而 `_orth` 的截断只有 rtol = 1e-6。结果，并集矩阵中奇异值低到 0.002–0.03 的方向，也就是与已有方向几乎重合的近重复方向，被当作完整的新方向保留下来。
  - overcomplete 扇区：给出 168 个家族方向，保留了 165 个；若只保留奇异值 > 0.5 的，剩 122 个，其中 21 个扇区不再 overcomplete。
  - 其他扇区：在 76 个扇区里也有 91 个这样的方向，说明这个问题不只存在于 overcomplete 扇区。
- **不是能级偏差造成的**：overcomplete 扇区里家族的 |level_deviation| 中位数是 0.26，其他扇区是 0.22，两者相近。按能量筛选方向没有选择性，所以不作为修正手段。
- **物理依据**：在精确的 CFT 里，不同 primary 的后裔彼此正交，也与所有 primary 正交，见共形表示论，以及 FFK 2602.04958 §3.1 的 |K|² 本征分解。在有限截断下，不同家族的像落到同一批态上，是截断和混合造成的假象。这种重叠不应被算作“更多的后裔方向”。

## 2. 规则（按顺序执行）

### R0 检测（已在 v0.4.0 中实现）
扇区 s 满足 d_P(s) + d_D,eff(s) > n_s 时，记为 overcomplete。这里 d_P 是该扇区 Δ≤Δ_max 的投影 primary 模式数，n_s 是分类基中该扇区的态数。

### R1 后裔方向去冗余（核心规则）
在每个 (pair, L) 的分类基上，用确定的顺序**逐个**加入家族方向，不再一次性取 `_orth(hstack)`：
- **顺序**：级数 n 从小到大 → 父 primary 的 Δ 从小到大 → 同一家族内按奇异值从大到小。理由是低级数、低父 Δ 的像受窗口截断影响最小。
- **接受条件**：设 A 为已接受的方向张成的空间，候选方向 u（单位向量）只有在 ‖(1−Π_A) u‖² ≥ 1 − g 时才被接受。g 取 `raw_class_weight`（0.9），不引入新参数。这个条件的含义是：如果一个方向有 90% 以上已经落在现有后裔空间里，它就不提供新的后裔方向，正好与“w_D ≥ 0.9 算 descendant”的语义一致。接受后，把残差 (1−Π_A)u 归一化，作为新方向。
- **记录**：被拒绝的方向，以及它与哪个父家族、哪一级重叠，都写入诊断表。
- **说明**：这一步不使用 primary 子空间，所以对 P 和 D 是对称的。

### R2 维数预算（R1 之后仍超出时才用）
如果某个扇区在 R1 之后仍有 d_P + d_D > n_s，就按 R1 的顺序从后往前丢弃方向，直到 d_D = n_s − d_P。被丢弃的方向记录为 `budget_dropped`。这就是你提的“家族方向数不超过扇区维数减 primary 维数”。它只对 R1 处理不了的少数扇区起作用：当前数据下预计约 5 个，主要是 N5 的单态扇区 55 L2，以及 81 L2。

### R3 对称冲突（不用 Gram–Schmidt 把冲突“消解”掉）
R1 和 R2 之后，如果某个后裔方向 u 与该扇区的 primary 子空间之间的 max cos² ≥ g：
- 把 u 移出后裔空间，标为 `conflict_direction`；
- 同时把对应的 primary 模式标为 `conflict_pair`，**不认证它为 P**；
- 原始能级如果 w_P ≥ g，判为 `ambiguous_primary_descendant_overlap`，原因写成“父 X 的第 n 级像与该 primary 重合”。

禁止的做法：先把后裔方向对 primary 做正交化，然后宣称 P 胜出。这正是交接文档明确警告的。

### R4 独立证据（只用来解除 R3 的冲突，不自动覆盖其他判定）
冲突对只有在下列证据中**至少一项支持某一方、且没有任何一项反对**时，才判给那一方；否则维持 ambiguous。
- **(a) 跨副本**：同一物理能级在**不处于** overcomplete 状态的另一个 (sA, sB) 块里有明确的 P 或 D。
- **(b) K² 预言**（FFK 2602 §3.2 的做法）：假如该态是父 X 的第 n 级后裔，CFT 给出的 λ = (2Δ₀+n−3)n + L(L+1) − L₀(L₀+1)。实测 K² < λ/2 支持 P；实测 K² 落在 [λ/2, 2λ] 内支持 D。区间沿用 v0.4.0 T6 中预先写定的值。
- **(c) 缩窗稳定**（T3）：不稳定时记为“反对”，任何一方都不认证。

### R5 适用范围（需要你决定）
- **选项 A（保守）**：R1–R4 只在 R0 检测出的 overcomplete 扇区里执行，其余扇区保持现状、逐字节不变。优点是影响面小。缺点是：同样的近重复方向，在另外 76 个扇区里仍然会虚增 w_D。
- **选项 B（一致）**：R1 在所有扇区执行，R2–R4 只在仍有冲突的地方执行。优点是规则统一。缺点是会改变一些非 overcomplete 扇区里的 w_D：部分 descendant 可能降为 mixed，需要逐态列出差异。
- **我的建议**：两种都做干跑，并排报告变化，由你选。正式版本只采用其中一个。

## 3. 不采用的方案
- **按能级偏差筛选方向**：如第 1 节所说，没有选择性。
- **先对 primary 正交化，再构造后裔空间**：会系统性地偏向 P。
- **只做标记、不改构造**（v0.4.0 现状）：可以作为后备方案，但会让 23 个能级一直停留在“信息不足”。

## 4. 干跑与验收（规则冻结后执行）
- **不改基线**：新建版本号（v0.5.0-dev），同时输出旧、新两套 w_D 和分类。
- **逐案报告**：24 个双通过副本和 1 个跨副本分裂，各自经过 R1–R4 之后的结果，以及依据的证据。
- **范围检查**：选项 A 下，非 overcomplete 扇区的输出必须逐字节不变；选项 B 下，列出所有改变了分类的能级，以及每个变化来自哪条规则、哪个被拒绝的方向。
- **复核**：T2–T7 用新的后裔空间重跑；轨迹、κ 阈值、OPE 数值本身都不变，只有身份状态可能变。
- **不使用**任何论文标签或一致率来比较两个选项。

## 5. 局限
- R1–R4 改进的是判定逻辑，并不能弥补物理窗口太小的问题。N5、N6 的小扇区本来就只有很少几个态。N5 已经不在主拟合窗口内（主拟合用 N6–12）。
- 要彻底解决 N12 的 4 个案例，最可靠的办法是在 3889 完成后，补上更大的窗口和缺失的边（例如 (0,0) L3→L4）。
- g = 0.9 沿用原约定，λ 区间沿用 T6，没有为这次修正引入新的数值参数。R1 的排列顺序是一个选择，干跑时会同时报告它对结果的影响（与 order-independent 的 SVD 截断比较）。
